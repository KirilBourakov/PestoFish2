Pestofish2
==============
Pestofish2 is a open source chess engine written in the C++ programming language. It is a significant improvement over the original [PestoFish](https://github.com/KirilBourakov/Pestofish), written as part of a first year final project. 


# Project Structure

## pestofish
PestoFish2's implimentation.

## evaluate
This folder contains scripts to compare new versions of pestofish to a previous ones. 

## frontend
A simple GUI to play manual games against differnet versions of pestofish.
